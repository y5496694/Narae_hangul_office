# 지역 설정과 메신저·예약 작업

일반 설정에서 교육청을 고르면 해당 지역의 업무포털 기본 주소를 저장합니다. 17개 주소와 확인 출처는 교무포털 패키지의 [지역 설정 안내](../vendor/narae-gyomu/packages/narae_gyomoo_portal/skills/narae-gyomu-work-portal/references/regions.md)를 따릅니다. 새 지역 로그인은 새 탭에서 시작하며 기존 문서는 보존합니다. 다른 지역의 인증서 보안 문서는 자동 재사용하지 않습니다.

충북 메신저는 포함된 CBE 전용 CLI로 현재 로그인 연결을 확인했습니다. [지역 메신저 CLI](https://github.com/y5496694/narae-messenger-cli)는 그 외 지역의 실제 설치 앱을 바인딩하는 공통 Windows UIA 어댑터를 제공합니다. 접근성 트리에서 읽은 snapshot·ref·창 제목·실행 파일 해시가 일치해야 변경합니다. 해당 앱이 접근성을 지원하지 않으면 전용 구현이 더 필요합니다. 지역별 전용 프로토콜 17종과 모든 지역의 실앱 업무를 완료했다는 의미는 아닙니다. 현재 실제 업무 시험은 충북만 합니다.

카카오톡 프로그램 사용을 켜면 포함된 [kakao-cli](https://github.com/y5496694/kakao-cli)를 에이전트와 결과 전송에 사용합니다. 나래 챗봇에서 받은 요청과 프롬프트는 유지하고 결과는 CLI가 확인한 나와의 채팅으로 제출합니다. 본인 방은 기존 로컬 보안 키의 MemoChat 종류로 확인합니다. 키나 본인 방을 확인하지 못하면 보내지 않습니다. 키 복구를 자동으로 수행하지 않습니다. 실제 제출과 서버 수신은 구분하고 결과 불명 발송을 자동 반복하지 않습니다.

예약 작업 탭에서 이름·cron 식·시간대·요청·결과 수신을 저장합니다. 기본 시간대는 Asia/Seoul이고 `0 8 * * 1-5`는 평일 오전 8시입니다. 현재 선택한 AI와 도구 승인 설정으로 실행합니다. 앱이 켜져 있어야 하며 PC 종료나 다른 작업 때문에 놓친 실행은 나중에 몰아서 처리하지 않습니다. 결과는 PC 에이전트 대화 또는 CLI의 나와의 채팅에 남깁니다.

나래 카톡 챗봇에 `cron`, `/cron`, `예약 목록`을 보내면 별도 기능으로 등록된 예약·켜짐 여부·최근 상태를 조회합니다. `cron 2`로 다음 페이지를 봅니다. 이 조회는 AI 작업을 생성하지 않습니다. 중계 서버와 PC 앱이 모두 이번 버전이어야 하며 오프라인에서는 마지막 동기화 목록으로 표시합니다. 예약 요청 본문은 이 목록에 업로드하지 않습니다.

2026-11-01 검증: 실제 Electron에서 17개 선택지·지역별 주소 저장과 예약 추가/재열람/수정/삭제를 확인했습니다. cron 시간대·중복 실행 방지·바쁜 슬롯 건너뛰기·전송 실패 후 미재실행, 계정별 챗봇 목록 분리를 회귀시험했습니다. PC 카카오톡의 본인 방 확인과 실제 결과 전송은 미검증입니다. 다른 지역 앱의 실제 계정·전송 시험도 미검증입니다. 이번 변경은 CLI·실행기·스킬 개선이며 모델 가중치를 새로 학습한 것이 아닙니다.
