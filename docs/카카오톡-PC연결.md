# 카카오톡 ↔ 나래 오피스 PC 연결 · 미리보기

## 이번 버전의 범위

공식 카카오 **채널 챗봇 스킬**을 연결하는 독립 중계 서버와 Windows 나래 한글 오피스의 실행기를 제공합니다. 개인 카카오 계정 자동 로그인이나 LOCO 연결은 없습니다. 기존 와니 데모·텔레그램 게이트웨이를 수정하거나 재기동하지 않습니다.

- 카카오 사용자별 나래 UID 발급, PC별 기기 자격 분리
- UID 입력 → PC 연결 요청 → 카톡의 일회용 코드 확인 → PC 최종 승인
- 승인 PC의 아웃바운드 HTTPS 폴링, 오피스의 기존 AI·문서 도구 실행, 결과 텍스트 반환
- 작업 폴더 문서 읽기와 구체적인 문서 생성·수정·PDF 출력의 PC별 일회 승인
- 연결 해제·작업 중단·오프라인 안내·중복 방지·재시작 후 불확실 작업의 자동 재실행 차단

**계정당 승인 PC 한 대, PC에서 선택한 오피스 AI 사용**이 첫 버전의 범위입니다. CBE·이지에듀·포털 실행, 여러 PC 선택, 파일 업로드·카톡 파일 첨부는 아직 연결하지 않았습니다. 생성 문서는 해당 PC 작업 폴더에 남고 카톡에는 텍스트만 전달합니다. 한컴 전용 열린 문서 편집·PDF 출력에는 기존과 같이 설치된 한컴오피스 한글이 필요합니다.

## 사용 순서

1. 별도로 설정된 나래 채널에 `내 UID`를 보냅니다.
2. 오피스 상단 **카카오톡 연동**에서 운영자가 알려 준 HTTPS 중계 주소, UID, PC 이름을 입력합니다. 권한·데이터 경유 안내를 읽고 문서 읽기 동의를 체크합니다.
3. **UID로 연결 요청**을 누르고, PC 화면의 `연결 <코드>` 문장을 같은 카톡 사용자로 보냅니다. 코드는 5분 이내, 한 번만 사용할 수 있습니다. UID 자체는 비밀번호가 아닙니다.
4. PC에서 상태를 새로고침하고 **이 카톡 사용자의 PC 연결 승인**을 누릅니다. UID를 아는 다른 사람이 자기 PC를 신청해도 해당 카톡 사용자의 확인 없이 승인할 수 없습니다.
5. 카톡으로 문서 요청을 보냅니다. 문서 변경은 PC 화면의 실제 도구명·인자·파일 경로·본문을 확인한 뒤 **이 변경 승인**을 눌러야 실행됩니다. 승인은 해당 한 건에만 유효하고 2분 뒤 만료됩니다.
6. `결과 확인`, `연결 상태`, `중단`, `연결 해제`를 사용할 수 있습니다. PC의 **PC 연결 해제**도 서버 자격을 폐기하고 로컬 기기 토큰을 제거합니다.

PC와 앱이 꺼져 있을 때의 요청은 켜진 뒤 몰래 실행하지 않습니다. 처리 중 연결이 끊겨 완료 여부를 확인할 수 없으면 **불확실**로 표시하며 자동 재시도하지 않습니다. 이미 수행된 변경은 중단·연결 해제로 되돌리지 않습니다. 오피스 재실행 시 승인된 기기를 다시 연결하지만 미완료 도구는 다시 실행하지 않습니다.

다른 PC로 옮기거나 기기 파일을 잃어버렸다면 카톡에서 `연결 해제`를 보낸 뒤 새로 연결하세요. 중계 서버에 접근할 수 없어 PC 해제를 확인하지 못하면 로컬은 즉시 차단하고, 서버 해제 미확인을 별도로 표시합니다.

## 중계 서버 운영

Node.js 24 이상이 필요합니다. 개인 자료가 없는 **별도 운영 데이터 디렉터리**와 전용 HTTPS 주소를 사용하세요. 개발용 임시 터널은 주소·프로세스가 사라질 수 있어 상시 서비스가 아닙니다. 최종 사용자에게 스킬 비밀 경로를 입력시키지 않고 HTTPS 기본 주소만 제공합니다.

```powershell
$env:NARAE_RELAY_HOME = "$env:LOCALAPPDATA\NaraeKakaoRelay"
$env:NARAE_KAKAO_BOT_ID = "공식 챗봇의 실제 bot.id"
$env:NARAE_RELAY_PORT = "8941"
npm run relay:kakao
```

서버는 `127.0.0.1:8941`에만 바인딩합니다. 역방향 프록시에서 TLS와 요청 제한을 적용하고 외부에는 해당 중계 경로만 노출하세요. 기존 서비스 포트를 바꾸거나 PC 인바운드 포트를 열 필요가 없습니다. 사용자 PC는 이 HTTPS 서버로 나가기만 합니다.

첫 실행 시 `NARAE_RELAY_HOME/skill-secret.txt`에 비밀 스킬 키, `relay.json`에 상태를 저장합니다. 카카오 i 오픈빌더의 스킬 URL을 `https://중계주소/kakao/<비밀 키>`로 설정하고 해당 채널의 블록·폴백 경로를 배포합니다. 스킬 URL은 비공개 관리자 설정으로만 다루고 Git·일반 로그·대화·스크린샷에 넣지 마세요. 서비스 구성자가 해당 카카오 채널의 약관·배포·콜백 사용 조건을 확인해야 합니다. 다른 채널과 기존 와니 채널의 설정을 임의로 덮어쓰지 마세요.

`/health`는 민감 정보 없는 상태 확인입니다. `/v1/pairings`는 UID로 미승인 요청만 생성하며, `/v1/device/*`는 기기별 Bearer 자격이 필요합니다. UID만으로 문서 실행·기기 최종 승인·타 사용자 작업 조회를 허용하지 않습니다. 별도 공개 관리자 API·임의 셸 실행 API는 없습니다.

단일 서버 프로세스가 상태 파일을 소유하는 작은 미리보기용 구조입니다. 여러 프로세스/서버가 같은 JSON 상태 파일을 공유하면 안 됩니다. PC는 약 2초 간격으로 폴링하며 장시간 작업은 heartbeat로 연결을 확인합니다. 운영 규모 확대에는 DB 트랜잭션·분산 잠금·보관 관리·감사 정책을 먼저 추가해야 합니다.

## 보안·개인정보 경계

- **PC 저장:** 기기 토큰은 기존 Windows 사용자 DPAPI 저장소 `data/kakao-device.bin`에 암호화합니다. AI 토큰·API 키와는 다른 슬롯입니다. 일반 설정·렌더러 IPC 응답에는 토큰이 없습니다. 로컬 원격 이력은 기기 연결 ID별 별도 파일이며 오피스 일반 대화에 합치지 않습니다.
- **전송:** 원격 요청과 답변, AI 처리에 사용된 문서 내용은 카카오·중계 서버·선택한 AI 제공자를 통과할 수 있습니다. 원본 문서·학교 로그인·인증서·AI 자격은 기본적으로 PC에 두지만, 사용자가 문서 내용을 요청하면 내용이 답변에 포함될 수 있습니다. 중계 운영자는 요청·답변에 접근할 수 있습니다.
- **서버 저장:** UID, 해시한 카카오 식별자, 기기 이름·승인 상태·자격 해시를 보관합니다. 요청·결과 텍스트는 최대 7일, 중복 판별 키는 24시간 보관합니다. 연결 해제는 자격 폐기이며 UID·기존 이력 즉시 삭제 기능은 아닙니다. 운영자가 데이터 삭제·백업 만료 정책을 마련해야 합니다. 서버 파일 접근 권한과 저장장치 암호화를 별도로 적용하세요.
- **경로·도구:** 작업 폴더 밖 경로, symlink/junction 탈출, 도구 명세에 없는 출력·백업 인자, 임의 명령·Python·페이지 JS는 차단합니다. 기존 파일 생성 덮어쓰기는 차단합니다. 파일 편집에는 기존 엔진의 해시·백업·미저장 문서 보호도 적용합니다.
- **쓰기 승인:** 모델이 제안한 변경을 PC 사용자가 구체적으로 확인해야 합니다. 도구명·인자 해시에 묶인 일회 승인이고 만료·거절·중단 시 실행하지 않습니다. 학교 메시지 전송·공문 상신은 이 버전에 도구 자체가 없습니다.
- **콜백:** HTTPS의 정확한 `bot-api.kakao.com` 주소만 허용하고 리다이렉트를 따르지 않습니다. 일회성 주소는 디스크에 저장하지 않고 최대 290초만 메모리에 둡니다. HTTP 200이라도 JSON `status: SUCCESS`가 아니면 접수 성공으로 표시하지 않습니다. 전송은 1회 시도하고 불확실한 전송을 자동 반복하지 않습니다. `callback_accepted`는 카카오 서버 접수 수준이며 사용자 기기 도착의 독립 증거가 아닙니다. 만료·거부·미제공 때는 `결과 확인`으로 조회합니다.
- 요청은 최대 4,000자, 결과 보관은 최대 12,000자입니다. 긴 결과는 여러 카톡 텍스트 페이지로 나눕니다. 미리보기의 제한을 실무 대량 처리 보장으로 해석하지 마세요.

`NARAE_KAKAO_ALLOW_LOOPBACK=1`은 합성 로컬 검사 전용입니다. 일반 앱은 HTTPS 서버만 받으며 개발 설정을 운영 사용자에게 적용하지 않습니다.

## 재현 가능한 검사

```powershell
npm ci
# 앱 전용 Python 또는 개발 venv에 requirements.txt 준비
$env:NARAE_OFFICE_PYTHON = "C:\검증용 Python\python.exe"
npm test
npm run test:kakao:desktop
```

단위·보안 검사는 계정/챗봇 격리, 다른 사용자의 확인 코드·결과 접근 거부, PC 승인 전 실행 차단, 만료·해제·중복·재시작·callback 판별·SSRF·경로 탈출·승인 경쟁조건을 포함합니다. Windows GitHub Actions에도 같은 검사를 연결합니다.

데스크톱 검사는 **합성 카카오 요청 + 명시적인 AI 모의 응답**을 사용하지만 **실제 Electron UI, DPAPI, 아웃바운드 HTTP, 나래 CLI와 HWPX 엔진**을 실행합니다. 실제 문서 생성/읽기, 클릭 전 쓰기 미실행, 승인 후 실제 저장·재조회, 거절 시 파일 미생성, 앱 재실행 후 기기 유지, 해제 후 기기 자격 제거를 확인합니다. 개인·학교 데이터나 실제 카카오 메시지 발송은 사용하지 않습니다.

이 검사 통과만으로 **실제 카카오톡 왕복, 실제 유료 AI 응답, 한컴 창 편집·PDF 출력, CBE·이지에듀·포털 실무 동작**까지 검증됐다고 말할 수 없습니다. 실제 채널 배포와 사용자 기기의 실메시지 왕복은 별도 운영 확인이 필요합니다.
