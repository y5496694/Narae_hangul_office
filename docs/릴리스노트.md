# 나래 한글 오피스 0.8.0

나래한글 엔진 기반, 한컴오피스 2024 연동 HWP/HWPX 문서 작업 공간입니다. MIT 라이선스로 앱 소스와 설치 스크립트를 공개합니다.

- 기존 파일 수정 후 원래 한글 창을 재사용하도록 처리해, 내용 없는 빈 문서 창이 남는 문제를 고쳤습니다.
- ChatGPT OAuth를 기본값으로 제공하며 OpenAI API·Claude Console OAuth·Claude API를 함께 지원합니다.
- 실제 한글 본문·문단 서식 편집, 나래한글 엔진의 문서 생성·파일 편집, 한글 PDF 미리보기와 사본 출력을 제공합니다.
- 사용자별 설치와 전용 Python 환경, Windows 암호화 자격 증명 저장을 지원합니다.

`Narae-Hangul-Office-0.8.0-windows-x64.zip`을 내려받아 압축을 풀고 **설치.cmd**를 실행하세요. Windows x64, 한컴오피스 2024 한글, Node.js 24, Python 3.13이 필요합니다. 첫 설치는 인터넷에 연결되어 있어야 합니다.

Claude Console OAuth는 Pro/Max 구독과 별개의 API 사용량 과금입니다. 실제 계정 로그인은 사용자가 앱 설정에서 승인합니다.
