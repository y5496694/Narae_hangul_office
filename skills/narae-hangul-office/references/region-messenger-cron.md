# 지역·카카오톡 프로그램·예약 작업

설정 → 일반의 교육청 지역이 업무포털 주소와 메신저 도구 선택의 기준이다. 17개 주소의 원본은 고정된 교무포털 패키지 `regions.cjs`다. 기본은 충북이다. 새 지역 로그인은 새 탭에서 시작하여 기존 문서와 탭을 보존하며 지역이 다른 DPAPI 보안 문서를 사용하지 않는다. 주소와 공통 어댑터 등록은 실제 업무 검증이 아니다.

충북은 기존 CBE 전용 CLI를 사용한다. 다른 지역은 `gyomu_regional_messenger`의 status부터 확인하고 해당 지역 앱의 실제 PID·HWND·실행 파일을 bind한다. inspect의 실제 snapshot과 ref만 사용한다. 접근성 미지원 앱은 해당 설치물의 REA 근거를 보고 전용 어댑터를 구현해야 한다. 다른 지역을 충북 세션으로 처리하지 않는다. 실제 업무 시험 지역은 충북이다.

설정 → 일반 → **카톡 프로그램 사용**을 켜면 `gyomu_kakao`가 나타난다. 포함된 kakao-cli의 doctor·방 조회·로드된 메시지·검색·명시한 전송·첨부 전송을 사용한다. doctor의 창 발견은 계정 로그인 확인이 아니다. 보낸 메시지의 submitted_unconfirmed는 서버 수신 확인이 아니다. 같은 요청의 결과 불명 전송을 자동 반복하지 않는다.

나래 챗봇 요청·프롬프트·계정 연결은 유지한다. 결과 전송은 카카오톡 CLI로 확인한 **나와의 채팅**을 사용한다. self-room은 기존 DPAPI 키로 MemoChat 종류를 확인하며 키가 없으면 보내지 않는다. 일반 전송 때문에 메모리 키 복구를 자동 시작하지 않는다. 결과 전송이 실패해도 완료된 PC 업무를 다시 실행하지 않는다.

예약은 설정 → **예약 작업**에서 만들고 조회한다. cron은 분·시·일·월·요일의 다섯 필드와 IANA 시간대를 사용한다. 앱이 실행 중일 때 현재 AI·도구 승인 설정으로 작업한다. PC 종료·작업 중 놓친 실행은 나중에 몰아서 실행하지 않는다. 실행 슬롯을 먼저 기록하며 재시작 때 미확인 작업을 자동 재실행하지 않는다. 사용자 요청이 없는 예약을 임의 생성하지 않는다.

CLI는 `narae-office cron list`, `cron save 설정.json`, `cron remove ID`다. 에이전트의 `gyomu_cron`은 목록·최근 상태 조회만 제공한다. 카톡 나래 챗봇의 `cron`, `/cron`, `예약 목록`은 별도 목록 조회이며 AI 업무를 생성하지 않는다. PC가 오프라인이면 마지막 동기화 목록임을 표시한다. 중계 서버에도 업데이트가 적용되어야 이 명령이 동작한다.
